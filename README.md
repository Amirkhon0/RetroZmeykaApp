# 🐍 Змейка (Retro Nokia 3310 Snake)

Аутентичная классическая мобильная ретро-игра **«Змейка»** (Snake II) в стиле легендарных кнопочных телефонов Nokia 3310. Разработана на современном стеке (React 19 + TypeScript + Tailwind CSS) с полной поддержкой PWA, офлайн-режима и возможностью публикации в Google Play как APK/AAB.

---

## 📱 Особенности и возможности

- **Два режима отображения**:
  - **Корпус Nokia 3310**: детально воссозданный кнопочный телефон с динамиком, серебристым логотипом, функциональными софт-клавишами `[Меню]`, `[OK]`, `[Сброс]` и цифровой клавиатурой.
  - **Сенсорный режим (Touch Arcade)**: полноэкранный вид с эргономичным крестовым D-Pad контроллером.
- **Управление**:
  - **Смартфон**: свайпы пальцем по экрану в любом направлении или виртуальные кнопки с тактильной отдачей (Haptic feedback).
  - **Цифровая клавиатура 3310**: `2` (вверх), `4` (влево), `6` (вправо), `8` (вниз), `5` (пауза).
  - **Компьютер**: Стрелки клавиатуры, клавиши `WASD` и цифровой блок Numpad.
  - Защита от случайных разворотов на 180° в собственное тело.
- **3 режима игры**:
  - **Без стен** — прохождение сквозь границы экрана (как в Snake II).
  - **Со стенами** — классическое столкновение с краями игрового поля.
  - **Лабиринт** — динамические препятствия внутри поля.
- **Бонусные жуки**:
  - Каждые 5 съеденных яблок на 10 секунд появляется насекомое с таймером и повышенными очками.
- **5 ретро-тем LCD-дисплея**:
  - *Nokia 3310* (классический матричный зелёный).
  - *Game Boy* (ностальгический оливковый).
  - *Amber CRT* (тёплый янтарный терминал).
  - *Чёрно-белый LCD* (высококонтрастный монохром).
  - *Неон* (киберпанк матрица).
- **Звук и отклик**:
  - 8-битный процедурный аудио-синтезатор (Web Audio API) без сторонних тяжелых аудиофайлов.
  - Тактильная вибрация при поворотах, поедании еды и проигрыше.
- **PWA и работа без интернета**:
  - Сервисный воркер (Service Worker) кэширует ресурсы — игра работает на 100% автономно в самолете или без сети.
  - Установка прямо на экран смартфона одной кнопкой («Установить на телефон»).
- **Полноэкранный режим**:
  - Поддержка `display: fullscreen` и скрытие системных панелей для максимального погружения.

## 🚀 Быстрый старт и разработка

### Требования
- Node.js 18+
- npm или bun / pnpm

### Установка зависимостей
```bash
npm install
```

### Запуск локального сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Сборка проекта для продакшена
```bash
npm run build
```
Скомпилированные файлы появятся в папке `dist/`.

## 🌐 Публикация на GitHub Pages

В репозитории уже настроен автоматический пайплайн **GitHub Actions** (`.github/workflows/deploy.yml`).

Чтобы включить автоматическую публикацию:
1. Запушьте код в ваш репозиторий на GitHub (`main` или `master`).
2. Перейдите в настройки репозитория: **Settings** → **Pages**.
3. В выпадающем меню **Build and deployment** > **Source** выберите **GitHub Actions**.
4. GitHub сам автоматически скомпилирует проект и развернет его на `https://<ваш-логин>.github.io/<репозиторий>/`.

## 📦 Сборка APK для Android и Google Play

Благодаря соответствию спецификациям PWA (наличие `manifest.json`, иконок `maskable` и `sw.js`), игру можно упаковать в нативный Android-файл `.apk` или `.aab` за пару минут:

### Способ 1: Онлайн через PWABuilder (быстрее всего)
1. Откройте [pwabuilder.com](https://www.pwabuilder.com/).
2. Введите URL опубликованной игры на GitHub Pages.
3. Нажмите **Package for Stores** → **Android**.
4. Скачайте готовый `.apk` для установки на телефон или `.aab` для публикации в Google Play Console.

### Способ 2: Через Capacitor (локально в Android Studio)
```bash
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Змейка" "com.retro.snake" --web-dir=dist
npm run build
npx cap add android
npx cap open android
```
Затем в Android Studio: `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`.

## 🛠 Стек технологий

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 6
- **Стилизация**: Tailwind CSS 4
- **Иконки**: Lucide React
- **Анимации и эффекты**: Canvas-confetti, Motion
- **Звук**: Web Audio API (чистый 8-битный синтез на генераторах частот)
- **PWA**: Service Worker Cache API, Web App Manifest
